# FORET Tavares HTML

Proyecto HTML/CSS estático creado desde la guía Word de Joan.

## Estructura

- `index.html`: entrada principal, redirige a francés.
- `fr/index.html`: idioma principal.
- `es/index.html`: versión española.
- `pt/index.html`: versión portuguesa.
- `legal/index.html`: mentions legales, privacidad y cookies básicas.
- `styles.css`: sistema visual completo.
- `assets/`: imagen real extraída del Word y recorte del logo.

## Datos a confirmar antes de publicar

- Email real de Antonio para reemplazar `contact@foret-tavares.fr`.
- Nombres exactos de servicios y material disponible.
- Horario de atención, si se quiere mostrar.
- SIRET, responsable legal y datos del hosting para completar las páginas legales.
- Fotos reales adicionales: remolques, maquinaria y trabajos terminados.

## Uso

Abrir `fr/index.html` en el navegador. Para publicar, subir la carpeta a un hosting estático o adaptar el contenido a Next.js/Vercel.
